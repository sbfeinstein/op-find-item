# 1Password Find Item

1Password Find Item is a command-line tool for searching item fields across your 1Password vaults.

## Getting started

1Password Find Item searches field values, including password and other secret fields, without printing the matched values. It uses the official 1Password SDK and desktop-app authentication.

1. [Install the CLI](installation.md).
2. [Configure account authentication](authentication.md).
3. [Search your items](usage.md).

See the [API reference](api.md) for the package's Python API.
